# KushalAI Frontend — Requirements
#
# This is a frontend-only project. There is no backend, database, or API server.
# All data is synthetic/mock data bundled inside the frontend (see src/data/).

## Runtime
Node.js >= 18.x
npm >= 9.x

## Core dependencies (installed via `npm install`, pinned in package.json)
react ^18.3.1
react-dom ^18.3.1
react-router-dom ^6.26.0
lucide-react ^0.383.0
recharts ^2.12.7
framer-motion ^11.3.0

## Dev dependencies
vite ^5.4.0
@vitejs/plugin-react ^4.3.1

## Setup
1. npm install
2. npm run dev      -> starts local dev server (default: http://localhost:5173)
3. npm run build    -> production build to /dist
4. npm run preview  -> preview the production build locally

No environment variables, API keys, or external services are required.
